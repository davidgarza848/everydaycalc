# EverydayCalc

A static, mobile-friendly calculator website hosted on GitHub Pages.

## Files
- `index.html` — homepage and calculator interface
- `styles.css` — styling
- `script.js` — calculator logic, including weekly work schedule totals
- `privacy.html` — privacy policy draft; review it before enabling analytics/ads
- `contact.html` — feedback page linking to the public GitHub Issues page
- `robots.txt` and `sitemap.xml` — basic search-engine discovery files

## Publish updates
Upload the updated files to the root of the `everydaycalc` GitHub repository and commit the changes. GitHub Pages should redeploy automatically.

The Work Schedule Calculator totals up to seven daily shifts, subtracts unpaid break minutes, supports overnight shifts, and can estimate gross weekly pay when an hourly wage is entered.

## Important
The paycheck estimator is a simplified estimate and does not calculate actual tax withholding. Compound interest is illustrative and not a guarantee. Review all text and policies before applying for an ad network. Ad placeholders are not active ads.
