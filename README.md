# EverydayCalc

**Live site:** [https://evrydaycalc.com](https://evrydaycalc.com)

A static, mobile-friendly calculator website hosted on GitHub Pages. Fast, free tools for everyday math — no account required. Calculations run entirely in the browser.

## Features

- Instant (live) results as you type
- Formula shown with every result
- Copy-result button
- Deep links (`#paycheck`, `#bmi`, etc.) so you can bookmark or share a specific calculator
- Categories + search
- Responsive design
- Privacy-focused (inputs stay on-device)

## Calculators

**Work & pay** — Paycheck Estimator, Hourly to Salary, Time Card, Overtime Pay, Work Schedule  
**Money** — Loan Payment, Compound Interest  
**Shopping** — Sales Tax, Discount  
**Everyday** — Tip & Split Bill, Percentage, Grade, Age, Percentage Change, Days Between Dates  
**Health** — BMI Calculator

## Publish updates

Commit changes to the `main` branch of this repository. GitHub Pages redeploys automatically.

## Important notes

- Paycheck and tax-related tools are simplified estimates only.
- Compound interest and BMI results are illustrative / screening tools, not professional advice.
- Review the privacy policy and ad setup before relying on AdSense revenue.
